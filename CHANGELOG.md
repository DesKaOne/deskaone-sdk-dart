# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## 0.1.0

- Initial SDK foundation.
- ProxyConfig and ProxyPicker.
- TCPClient with direct/proxy/TLS support.
- HTTP, SOCKS4, SOCKS5 handlers.
- HttpClient over TCPClient.
- WebSocketClient over TCPClient.
- Utility helpers.
- SecureStorage.
- SQLite/PostgreSQL database abstraction.
